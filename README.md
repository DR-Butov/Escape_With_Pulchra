<summary>English</summary>

Escape With Pulchra is a mod for SPT that adds Pulchra Fellini as an AI companion.

Required SPT version: 4.1.x

A video showcasing the mod's content: https://www.youtube.com/watch?v=lvCLQEibSM4

Also: https://www.youtube.com/watch?v=tIYyUJPTBxI (Outdated)

Installation:
1. Download the latest version of the mod.
2. Open the zip file and extract it to your SPT folder.
3. Enter the game and meet your new companion.

**Required modifications (or their newer versions):**
1. BigBrain -  1.5.0
2. SAIN - 4.5.1
3. WTT - CommonLib 3.0.6 

Available localizations: English, Russian.

Created with the help of Claude Code.

<summary>Русский</summary>

Escape With Pulchra - это мод для SPT, добавляющий в качестве ИИ-компаньона Пульхру Феллини.

Требуемая версия SPT: 4.1.x

Видео, демонстрирующее контент мода: https://www.youtube.com/watch?v=lvCLQEibSM4

Также: https://www.youtube.com/watch?v=tIYyUJPTBxI (Устарело)

Установка:
1. Скачайте последнюю версию мода.
2. Откройте ZIP-файл и распакуйте его содержимое в вашу SPT папку.
3. Зайдите в игру и встретьтесь со своим новым компаньоном.

**Требуемые модификации (или их более новые версии):**
1. BigBrain -  1.5.0
2. SAIN - 4.5.1
3. WTT - CommonLib 3.0.6 

Доступные локализации: Английская, Русская.
